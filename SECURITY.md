# Security policy

Report vulnerabilities privately to Jordi Murgó at <jordi.murgo@gmail.com>.
Do not attach signatures, datasets, manifests, embeddings, checkpoints, access
tokens, or other sensitive material to a report.

Only the latest release is supported. Training data and checkpoints are treated
as untrusted local inputs. See `docs/SECURITY.md` for the threat model and the
reference offline execution profile.
